# 🚀 Projeto Ford Enter - Desenvolvimento Web

Este projeto foi desenvolvido como parte do programa Ford Enter em parceria com o SENAI, com o objetivo de aplicar na prática conhecimentos em desenvolvimento web.

## 📌 Sobre o projeto
O sistema simula um ambiente de aplicação web, utilizando conceitos fundamentais de programação, estruturação de páginas e interação com o usuário.

## 🛠 Tecnologias utilizadas
- HTML
- CSS
- JavaScript

## 🎯 Objetivo
Praticar e consolidar conhecimentos em desenvolvimento web, além de evoluir habilidades em lógica de programação e construção de interfaces.

## 🚀 Aprendizados
- Estruturação de páginas web
- Uso de lógica de programação
- Organização de código
- Experiência com projetos reais
